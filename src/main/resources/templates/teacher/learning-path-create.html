Tạo lộ trình học mới

Lỗi
Chưa có môn học nào. Admin cần thêm môn học trước.
Huỷ
Lưu ý
  • Sau khi tạo, bạn sẽ được chuyển thẳng vào trang quản lý Node.
  • Thêm node để xây dựng nội dung lộ trình (UC14).
  • Gắn học liệu (TEXT / VIDEO / FILE / LINK) vào từng node (UC17).
  • Lộ trình được dùng khi tạo lớp học.
